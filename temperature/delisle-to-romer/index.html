About this conversion

This page converts delisle (°De) into romer (°Ro) using the fixed relationship °Ro = °De × -0.35 + 60.

Worked example: to convert 25°De to °Ro, apply the formula: 25 × -0.35 + 60 = 51.25°Ro.

Reverse conversion: °De = (°Ro − 60) ÷ -0.35.

Accuracy: temperature scale relationships are fixed by definition, so this conversion is exact; any imprecision comes only from the number of decimal places shown.
