Frequently asked questions

What is the source unit in this conversion?

The source unit is the rankine (°R). Rankine is an absolute temperature scale that uses Fahrenheit-sized degrees.

What is the destination unit in this conversion?

The destination unit is the kelvin (K). Kelvin is the SI absolute temperature scale, where 0 K is absolute zero.

How do I convert rankine to kelvin?

Use the formula K = °R × 0.555556 + 0. For example, 25°R converts to 13.89K.

Why isn't this just a simple multiplication like other unit conversions?

Unlike most physical quantities, temperature scales don't all share the same zero point. The Rankine scale is an absolute temperature scale using Fahrenheit-sized degrees, used in some US engineering fields. The kelvin is the SI base unit of temperature, defined so that absolute zero is exactly 0 K. Converting between them requires both a scaling factor and an offset, not a single ratio.

Is the rankine to kelvin conversion exact?

Yes. The formula K = °R × 0.555556 + 0 is a fixed, defined relationship between the two scales, so results are exact rather than estimated.

Can I convert kelvin back to rankine?

Yes. Rearranging the formula gives °R = (K − 0) ÷ 0.555556.

About this conversion

This page converts rankine (°R) into kelvin (K) using the fixed relationship K = °R × 0.555556 + 0.

Worked example: to convert 25°R to K, apply the formula: 25 × 0.555556 + 0 = 13.89K.

Reverse conversion: °R = (K − 0) ÷ 0.555556.

Accuracy: temperature scale relationships are fixed by definition, so this conversion is exact; any imprecision comes only from the number of decimal places shown.

Rankine: Rankine is an absolute temperature scale that uses Fahrenheit-sized degrees. Kelvin: Kelvin is the SI absolute temperature scale, where 0 K is absolute zero.

Background: The Rankine scale is an absolute temperature scale using Fahrenheit-sized degrees, used in some US engineering fields.
