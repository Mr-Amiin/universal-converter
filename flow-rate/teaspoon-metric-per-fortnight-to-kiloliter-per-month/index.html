From definition

Metric teaspoon per Fortnight (metric tsp/fn) is a volumetric flow rate unit that measures how much volume, expressed in metric teaspoon(s), passes a given point every fortnight. It is used to compare flow across pipes, pumps, channels, and instruments that report volume moved over that particular time interval.

About this conversion

This flow rate page converts Metric teaspoon per Fortnight (metric tsp/fn) to Kiloliter per Month (kL/mo) using the exact volumetric flow rate factor from the Universal Converter engine. A flow of one metric teaspoon every fortnight is the same physical flow as 1.08703125e-05 kiloliter(s) every month, so this page is useful for pipeline sizing, pump and pipe selection, HVAC airflow and liquid handling, irrigation and water-supply planning, and lab or industrial process calculations that mix metric, US customary, or imperial flow units. For example, a pump, pipe, or flow meter running at 1 metric tsp/fn is moving flow equivalent to 1.08703125e-05 kL/mo — handy when one spec sheet lists flow in metric teaspoon per fortnight and another lists it in kiloliter per month.

Metric flow units are built from SI volume and time units established under the metric system, while US customary flow units combine older trade-derived volume measures (like the gallon or cup) with standard time units, which is why the same physical flow rate looks very different when expressed in each system.
