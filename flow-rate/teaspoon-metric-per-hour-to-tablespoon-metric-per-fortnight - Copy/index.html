From definition

Metric teaspoon per Hour (metric tsp/h) is a volumetric flow rate unit that measures how much volume, expressed in metric teaspoon(s), passes a given point every hour. It is used to compare flow across pipes, pumps, channels, and instruments that report volume moved over that particular time interval.

About this conversion

This flow rate page converts Metric teaspoon per Hour (metric tsp/h) to Metric tablespoon per Fortnight (metric tbsp/fn) using the exact volumetric flow rate factor from the Universal Converter engine. A flow of one metric teaspoon every hour is the same physical flow as 112 metric tablespoon(s) every fortnight, so this page is useful for pipeline sizing, pump and pipe selection, HVAC airflow and liquid handling, irrigation and water-supply planning, and lab or industrial process calculations that mix metric, US customary, or imperial flow units. For example, a pump, pipe, or flow meter running at 1 metric tsp/h is moving flow equivalent to 112 metric tbsp/fn — handy when one spec sheet lists flow in metric teaspoon per hour and another lists it in metric tablespoon per fortnight.

Metric flow units are built from SI volume and time units established under the metric system, while US customary flow units combine older trade-derived volume measures (like the gallon or cup) with standard time units, which is why the same physical flow rate looks very different when expressed in each system.
