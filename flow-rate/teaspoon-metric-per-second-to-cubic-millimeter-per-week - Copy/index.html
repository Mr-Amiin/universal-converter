From definition

Metric teaspoon per Second (metric tsp/s) is a volumetric flow rate unit that measures how much volume, expressed in metric teaspoon(s), passes a given point every second. It is used to compare flow across pipes, pumps, channels, and instruments that report volume moved over that particular time interval.

About this conversion

This flow rate page converts Metric teaspoon per Second (metric tsp/s) to Cubic Millimeter per Week (mm3/wk) using the exact volumetric flow rate factor from the Universal Converter engine. A flow of one metric teaspoon every second is the same physical flow as 3024000000 cubic millimeter(s) every week, so this page is useful for pipeline sizing, pump and pipe selection, HVAC airflow and liquid handling, irrigation and water-supply planning, and lab or industrial process calculations that mix metric, US customary, or imperial flow units. For example, a pump, pipe, or flow meter running at 1 metric tsp/s is moving flow equivalent to 3024000000 mm3/wk — handy when one spec sheet lists flow in metric teaspoon per second and another lists it in cubic millimeter per week.

Metric flow units are built from SI volume and time units established under the metric system, while US customary flow units combine older trade-derived volume measures (like the gallon or cup) with standard time units, which is why the same physical flow rate looks very different when expressed in each system.
