How the formula works

Both imperial hundredweight per gallon and gram per liter measure the same physical quantity (mass per unit volume), so converting between them is a single multiplication. Multiply a value in imperial hundredweight per gallon by 13420.559859 to get gram per liter. To reverse the conversion, multiply a gram per liter value by 7.451254e-5 to get back to imperial hundredweight per gallon.
