How the formula works

Both kilogram per cubic foot and picogram per pint measure the same physical quantity (mass per unit volume), so converting between them is a single multiplication. Multiply a value in kilogram per cubic foot by 1.671007e13 to get picogram per pint. To reverse the conversion, multiply a picogram per pint value by 5.984416e-14 to get back to kilogram per cubic foot.
