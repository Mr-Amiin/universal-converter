How the formula works

Both metric ton per cubic meter and nanogram per teaspoon measure the same physical quantity (mass per unit volume), so converting between them is a single multiplication. Multiply a value in metric ton per cubic meter by 4.928922e9 to get nanogram per teaspoon. To reverse the conversion, multiply a nanogram per teaspoon value by 2.028841e-10 to get back to metric ton per cubic meter.
