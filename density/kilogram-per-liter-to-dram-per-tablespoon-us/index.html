How the formula works

Both kilogram per liter and dram per tablespoon measure the same physical quantity (mass per unit volume), so converting between them is a single multiplication. Multiply a value in kilogram per liter by 8.345404 to get dram per tablespoon. To reverse the conversion, multiply a dram per tablespoon value by 0.119826 to get back to kilogram per liter.
