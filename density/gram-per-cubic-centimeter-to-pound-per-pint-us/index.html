How the formula works

Both gram per cubic centimeter and pound per pint measure the same physical quantity (mass per unit volume), so converting between them is a single multiplication. Multiply a value in gram per cubic centimeter by 1.043176 to get pound per pint. To reverse the conversion, multiply a pound per pint value by 0.958611 to get back to gram per cubic centimeter.
