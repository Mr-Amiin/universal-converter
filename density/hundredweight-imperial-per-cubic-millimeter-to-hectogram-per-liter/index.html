How the formula works

Both imperial hundredweight per cubic millimeter and hectogram per liter measure the same physical quantity (mass per unit volume), so converting between them is a single multiplication. Multiply a value in imperial hundredweight per cubic millimeter by 5.080235e8 to get hectogram per liter. To reverse the conversion, multiply a hectogram per liter value by 1.968413e-9 to get back to imperial hundredweight per cubic millimeter.
