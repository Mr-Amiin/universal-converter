How the formula works

Both ounce per gallon and metric ton per cubic yard measure the same physical quantity (mass per unit volume), so converting between them is a single multiplication. Multiply a value in ounce per gallon by 0.005726 to get metric ton per cubic yard. To reverse the conversion, multiply a metric ton per cubic yard value by 174.646031 to get back to ounce per gallon.
