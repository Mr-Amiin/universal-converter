How the formula works

Both grain per pint and grain per milliliter measure the same physical quantity (mass per unit volume), so converting between them is a single multiplication. Multiply a value in grain per pint by 0.002113 to get grain per milliliter. To reverse the conversion, multiply a grain per milliliter value by 473.176473 to get back to grain per pint.
