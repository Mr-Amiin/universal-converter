How the formula works

Both ounce per fluid ounce and ounce per quart measure the same physical quantity (mass per unit volume), so converting between them is a single multiplication. Multiply a value in ounce per fluid ounce by 32 to get ounce per quart. To reverse the conversion, multiply a ounce per quart value by 0.03125 to get back to ounce per fluid ounce.
