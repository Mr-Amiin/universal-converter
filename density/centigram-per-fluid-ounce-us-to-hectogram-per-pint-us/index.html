How the formula works

Both centigram per fluid ounce and hectogram per pint measure the same physical quantity (mass per unit volume), so converting between them is a single multiplication. Multiply a value in centigram per fluid ounce by 0.0016 to get hectogram per pint. To reverse the conversion, multiply a hectogram per pint value by 625 to get back to centigram per fluid ounce.
