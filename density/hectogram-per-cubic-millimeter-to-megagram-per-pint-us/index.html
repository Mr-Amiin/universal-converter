How the formula works

Both hectogram per cubic millimeter and megagram per pint measure the same physical quantity (mass per unit volume), so converting between them is a single multiplication. Multiply a value in hectogram per cubic millimeter by 47.317647 to get megagram per pint. To reverse the conversion, multiply a megagram per pint value by 0.021134 to get back to hectogram per cubic millimeter.
