How the formula works

Both gram per milliliter and kilogram per milliliter measure the same physical quantity (mass per unit volume), so converting between them is a single multiplication. Multiply a value in gram per milliliter by 0.001 to get kilogram per milliliter. To reverse the conversion, multiply a kilogram per milliliter value by 1000 to get back to gram per milliliter.
