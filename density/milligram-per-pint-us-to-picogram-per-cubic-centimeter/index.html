How the formula works

Both milligram per pint and picogram per cubic centimeter measure the same physical quantity (mass per unit volume), so converting between them is a single multiplication. Multiply a value in milligram per pint by 2.113376e6 to get picogram per cubic centimeter. To reverse the conversion, multiply a picogram per cubic centimeter value by 4.731765e-7 to get back to milligram per pint.
