How the formula works

Both ounce per cubic millimeter and imperial hundredweight per liter measure the same physical quantity (mass per unit volume), so converting between them is a single multiplication. Multiply a value in ounce per cubic millimeter by 558.035714 to get imperial hundredweight per liter. To reverse the conversion, multiply a imperial hundredweight per liter value by 0.001792 to get back to ounce per cubic millimeter.
