Frequently asked questions

How do I convert pebibytes to terabits?

Multiply the pebibyte value by 9,007.199254740992. For example, 4 PiB × 9,007.199254740992 = 36,028.797018963968 Tb.

How do I convert terabits back to pebibytes?

Divide the terabit value by 9,007.199254740992, which is the same as multiplying by 0.00011102230246251565404236316680908203125.

Why does it matter whether this is measured in bits or bytes?

A byte is defined as exactly 8 bits, so every bit–byte conversion involves that fixed ×8 factor. Bits are the standard for network and internet connection speeds (e.g. Mbps), while bytes are the standard for file sizes and storage capacity — which is why a fast “Mb” connection and a large “MB” file are easy to mix up.

Is the pebibyte to terabit conversion exact?

Yes. Both units use fixed, defined prefixes (decimal and/or binary), so the conversion factor is exact rather than a rounded, measurement-based approximation, though remember decimal and binary prefixes diverge further apart as the scale grows.

Where is this conversion used in practice?

It comes up when comparing enterprise data centers, cloud storage platforms, large scientific datasets.

When would I use terabits instead of pebibytes?

Use whichever unit keeps the number easiest to read for the context: a mid-size corporate data center, or a major streaming service's video catalog is usually described in pebibytes, while an external hard drive, or a small business's shared file server reads more naturally in terabits.

About this conversion

This page converts pebibytes (PiB), a binary (IEC) unit of digital storage equal to 250 bytes, into terabits (Tb), a decimal (SI) unit of digital storage equal to 1012 bits.

This conversion is used when comparing enterprise data centers and external hard drives.

The formula is Tb = PiB × 9,007.199254740992, based on the fixed relationship between these two digital storage units.

The “pebi” binary prefix was introduced by the International Electrotechnical Commission (IEC 60027-2) to remove the ambiguity of reusing decimal SI prefixes for binary, power-of-two computer quantities, standardized in 1998. The “tera” prefix was formalized alongside giga at the 11th CGPM, standardized in 1960.

Digital storage prefixes follow the International System of Units (SI) for decimal units and the International Electrotechnical Commission (IEC) recommendations for binary units, keeping decimal and binary quantities unambiguous.
