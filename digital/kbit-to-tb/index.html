Frequently asked questions

How do I convert kilobits to terabytes?

Multiply the kilobit value by 1.25 × 10-10. For example, 4 Kb × 1.25 × 10-10 = 5 × 10-10 TB.

How do I convert terabytes back to kilobits?

Divide the terabyte value by 1.25 × 10-10, which is the same as multiplying by 8,000,000,000.

Why does it matter whether this is measured in bits or bytes?

A byte is defined as exactly 8 bits, so every bit–byte conversion involves that fixed ×8 factor. Bits are the standard for network and internet connection speeds (e.g. Mbps), while bytes are the standard for file sizes and storage capacity — which is why a fast “Mb” connection and a large “MB” file are easy to mix up.

Is the kilobit to terabyte conversion exact?

Yes. Both units use fixed, defined prefixes (decimal and/or binary), so the conversion factor is exact rather than a rounded, measurement-based approximation.

Where is this conversion used in practice?

It comes up when comparing short documents and emails, configuration files, compressed log entries.

When would I use terabytes instead of kilobits?

Use whichever unit keeps the number easiest to read for the context: a short text email or a single page of plain text is usually described in kilobits, while an external hard drive, or a small business's shared file server reads more naturally in terabytes.

About this conversion

This page converts kilobits (Kb), a decimal (SI) unit of digital storage equal to 103 bits, into terabytes (TB), a decimal (SI) unit of digital storage equal to 1012 bytes.

This conversion is used when comparing short documents and emails and external hard drives.

The formula is TB = Kb × 1.25 × 10-10, based on the fixed relationship between these two digital storage units.

The “kilo” prefix was part of the original French metric system, standardized in 1795. The “tera” prefix was formalized alongside giga at the 11th CGPM, standardized in 1960.

Digital storage prefixes follow the International System of Units (SI) for decimal units and the International Electrotechnical Commission (IEC) recommendations for binary units, keeping decimal and binary quantities unambiguous.
