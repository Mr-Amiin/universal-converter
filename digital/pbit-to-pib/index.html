Frequently asked questions

How do I convert petabits to pebibytes?

Multiply the petabit value by 0.11102230246251565404236316680908203125. For example, 4 Pb × 0.11102230246251565404236316680908203125 = 0.444089209850062616169452667236328125 PiB.

How do I convert pebibytes back to petabits?

Divide the pebibyte value by 0.11102230246251565404236316680908203125, which is the same as multiplying by 9.007199254740992.

Why isn't 1 petabit the same as 1 pebibyte?

The petabit (Pb) uses a power-of-10 base (1015), while the pebibyte (PiB) uses a power-of-2 base (250). They diverge as the prefix grows — at this tier the binary unit is about 800.72% larger, which is why operating systems (binary) and drive manufacturers (decimal) can report different sizes for the same file or disk.

Why does it matter whether this is measured in bits or bytes?

A byte is defined as exactly 8 bits, so every bit–byte conversion involves that fixed ×8 factor. Bits are the standard for network and internet connection speeds (e.g. Mbps), while bytes are the standard for file sizes and storage capacity — which is why a fast “Mb” connection and a large “MB” file are easy to mix up.

Is the petabit to pebibyte conversion exact?

Yes. Both units use fixed, defined prefixes (decimal and/or binary), so the conversion factor is exact rather than a rounded, measurement-based approximation, though remember decimal and binary prefixes diverge further apart as the scale grows.

Where is this conversion used in practice?

It comes up when comparing enterprise data centers, cloud storage platforms, large scientific datasets.

When would I use pebibytes instead of petabits?

Use whichever unit keeps the number easiest to read for the context: a mid-size corporate data center, or a major streaming service's video catalog is usually described in petabits, while a mid-size corporate data center, or a major streaming service's video catalog reads more naturally in pebibytes.

About this conversion

This page converts petabits (Pb), a decimal (SI) unit of digital storage equal to 1015 bits, into pebibytes (PiB), a binary (IEC) unit of digital storage equal to 250 bytes.

This conversion is used when comparing enterprise data centers and enterprise data centers.

The formula is PiB = Pb × 0.11102230246251565404236316680908203125, based on the fixed relationship between these two digital storage units.

The “peta” prefix was added at the 15th CGPM as computing needs grew, standardized in 1975. The “pebi” binary prefix was introduced by the International Electrotechnical Commission (IEC 60027-2) to remove the ambiguity of reusing decimal SI prefixes for binary, power-of-two computer quantities, standardized in 1998.

Digital storage prefixes follow the International System of Units (SI) for decimal units and the International Electrotechnical Commission (IEC) recommendations for binary units, keeping decimal and binary quantities unambiguous.
