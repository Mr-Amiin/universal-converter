Formula

KiB = Tb × 122,070,312.5

Tb = KiB ÷ 122,070,312.5

Exact under each unit's own definition, but note Tb is decimal (SI) while KiB is binary (IEC), so the two prefix families diverge at larger scales.

Worked example

Picture a small external hard drive, sized at about 2 Tb. Using the formula above: 2 Tb × 122,070,312.5 = 244,140,625 KiB.

Frequently asked questions

How do I convert terabits to kibibytes?

Multiply the terabit value by 122,070,312.5. For example, 4 Tb × 122,070,312.5 = 488,281,250 KiB.

How do I convert kibibytes back to terabits?

Divide the kibibyte value by 122,070,312.5, which is the same as multiplying by 8.192 × 10-9.

Why does it matter whether this is measured in bits or bytes?

A byte is defined as exactly 8 bits, so every bit–byte conversion involves that fixed ×8 factor. Bits are the standard for network and internet connection speeds (e.g. Mbps), while bytes are the standard for file sizes and storage capacity — which is why a fast “Mb” connection and a large “MB” file are easy to mix up.

Is the terabit to kibibyte conversion exact?

Yes. Both units use fixed, defined prefixes (decimal and/or binary), so the conversion factor is exact rather than a rounded, measurement-based approximation, though remember decimal and binary prefixes diverge further apart as the scale grows.

Where is this conversion used in practice?

It comes up when comparing external hard drives, small server storage, surveillance camera archives.

When would I use kibibytes instead of terabits?

Use whichever unit keeps the number easiest to read for the context: an external hard drive, or a small business's shared file server is usually described in terabits, while a short text email or a single page of plain text reads more naturally in kibibytes.

About this conversion

This page converts terabits (Tb), a decimal (SI) unit of digital storage equal to 1012 bits, into kibibytes (KiB), a binary (IEC) unit of digital storage equal to 210 bytes.

This conversion is used when comparing external hard drives and short documents and emails.

The formula is KiB = Tb × 122,070,312.5, based on the fixed relationship between these two digital storage units.

The “tera” prefix was formalized alongside giga at the 11th CGPM, standardized in 1960. The “kibi” binary prefix was introduced by the International Electrotechnical Commission (IEC 60027-2) to remove the ambiguity of reusing decimal SI prefixes for binary, power-of-two computer quantities, standardized in 1998.

Digital storage prefixes follow the International System of Units (SI) for decimal units and the International Electrotechnical Commission (IEC) recommendations for binary units, keeping decimal and binary quantities unambiguous.
