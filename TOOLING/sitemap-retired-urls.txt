# sitemap-retired-urls.txt
#
# URLs that were listed in the OLD single sitemap.xml but have deliberately been
# removed from the sitemap. generate_sitemaps.py / validate_sitemaps.py read this
# file so their "nothing valid was lost" guard can tell a documented removal from
# an accidental one.
#
# Why these 121: each is a root-level URL (e.g. /acres-to-square-feet/) that never
# had a page - no file exists at that path. The real page lives at the nested URL
# (e.g. /area/acres-to-square-feet/), which is now its canonical URL and is listed
# in the sitemap instead. These root URLs are NOT redirected: the site is served
# from GitHub Pages, for which no support for _redirects or server-side redirect
# rules is documented, so no redirect is configured. According to the repository
# files these URLs answered 404 before this change and still do (this has not been
# checked against the live site). See FINAL_PRE_DEPLOYMENT_REPORT.md.
#
# A URL must not appear here once it is listed in the sitemap or has a page of its
# own; validate_sitemaps.py (check 14) fails if that happens.
#
# Format: one absolute https URL per line; '#' starts a comment.
