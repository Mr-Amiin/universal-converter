How the formula works

Both decaohm and deciohm measure the same physical quantity, so converting between them is a single multiplication. Multiply a value in decaohms by 100 to get deciohms. To reverse the conversion, multiply a deciohm value by 0.01 to get back to decaohms.

Frequently asked questions

How do I convert decaohms to deciohms?

Multiply the decaohm value by 100. For example, 4 daΩ × 100 = 400 dΩ.

How do I convert deciohms back to decaohms?

Divide the deciohm value by 100, which is the same as multiplying by 0.01.

Is the decaohm to deciohm conversion exact?

Yes. Both are SI-prefixed units of resistance, so the conversion factor is an exact power of ten rather than a rounded, measurement-based approximation.

What is a decaohm used for?

The decaohm (daΩ) is commonly encountered in common resistor values in electronics (typical resistors run 220 Ω-10 kΩ).

About this conversion

This page converts decaohms (daΩ), an SI-prefixed unit of resistance equal to 101 ohms (decaohm = deca + ohm), into deciohms (dΩ), an SI-prefixed unit of resistance equal to 10-1 ohms (deciohm = deci + ohm).

This conversion is used when working with common resistor values in electronics (typical resistors run 220 Ω-10 kΩ).

The formula is dΩ = daΩ × 100, a fixed decimal ratio between these two SI-prefixed units.

The ohm is named after Georg Simon Ohm and was formally adopted at the 1881 International Electrical Congress in Paris. The “deca” prefix (da-, 101) was standardized in 1795.
