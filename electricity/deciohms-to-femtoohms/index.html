How the formula works

Both deciohm and femtoohm measure the same physical quantity, so converting between them is a single multiplication. Multiply a value in deciohms by 1.000000e+14 to get femtoohms. To reverse the conversion, multiply a femtoohm value by 1.000000e-14 to get back to deciohms.

Frequently asked questions

How do I convert deciohms to femtoohms?

Multiply the deciohm value by 100,000,000,000,000. For example, 4 dΩ × 100,000,000,000,000 = 400,000,000,000,000 fΩ.

How do I convert femtoohms back to deciohms?

Divide the femtoohm value by 100,000,000,000,000, which is the same as multiplying by 1 × 10-14.

Is the deciohm to femtoohm conversion exact?

Yes. Both are SI-prefixed units of resistance, so the conversion factor is an exact power of ten rather than a rounded, measurement-based approximation.

Why would anyone need a unit as small as the femtoohm?

The femtoohm (fΩ) shows up in the resistance of thick copper busbars and superconducting contacts, where the base ohm would be an inconveniently large unit for the quantities involved.

What is a deciohm used for?

The deciohm (dΩ) is commonly encountered in common resistor values in electronics (typical resistors run 220 Ω-10 kΩ).

About this conversion

This page converts deciohms (dΩ), an SI-prefixed unit of resistance equal to 10-1 ohms (deciohm = deci + ohm), into femtoohms (fΩ), an SI-prefixed unit of resistance equal to 10-15 ohms (femtoohm = femto + ohm).

This conversion is used when working with common resistor values in electronics (typical resistors run 220 Ω-10 kΩ).

The formula is fΩ = dΩ × 100,000,000,000,000, a fixed decimal ratio between these two SI-prefixed units.

The ohm is named after Georg Simon Ohm and was formally adopted at the 1881 International Electrical Congress in Paris. The “deci” prefix (d-, 10-1) was standardized in 1795.
